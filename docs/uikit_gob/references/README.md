# Referencias visuales — UI Kit v3.0.1

Capturas PNG exportadas desde el kit (o Figma), versionadas en el repo y enlazadas desde [`../../DESIGN_SYSTEM.md`](../../DESIGN_SYSTEM.md) (MiINAPI v2.0.0-gob).

## Cómo usar

1. Coloca o renombra archivos en esta carpeta: `docs/uikit_gob/references/`.
2. Enlaza desde `docs/DESIGN_SYSTEM.md` con rutas relativas a `docs/` (ej. `uikit_gob/references/1.PNG`).
3. Para implementación por fases, ver [`../../UI_MIGRATION_PLAN.md`](../../UI_MIGRATION_PLAN.md).
